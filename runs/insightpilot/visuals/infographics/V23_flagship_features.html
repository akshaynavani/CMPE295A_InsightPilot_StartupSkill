Why the loop and not the feature

Each element makes the next one cheaper

A visible plan shortens verification. Per-hop verification makes an override targeted. An override feeds the binding store. Better bindings shorten the next plan, and a shorter plan compounds less error. Ship hop-level lineage without that structure and what you have shipped is a log file.

The concession that keeps this honest

One untested claim holds features 15 to 18 up

If verification is not cheaper than re-derivation, those four are ceremony. The beachhead analyst's own objection says it is not.

The missing feature, on purpose

Multi-hop weakness gets a practice

Build the harness and the fixed question set before the agents, then publish the accuracy number. That is feature one in the build order and not a feature on this chart.
